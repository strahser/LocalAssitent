## 🌐 1. Браузерная автоматизация

### a) browser-use — стандарт де-факто (93k ⭐, Python)

**GitHub:** https://github.com/browser-use/browser-use [[2]]

Это **главная библиотека** для браузерной автоматизации агентами. Работает с Ollama напрямую:

```python
from browser_use import BrowserSession
from browser_use.llm.ollama.chat import ChatOllama

llm = ChatOllama(model="qwen2.5vl:7b")  # или qwen3-vl
browser_session = BrowserSession()
agent = Agent(
    task="Найди и спарси цены с сайта X",
    llm=llm,
    browser_session=browser_session
)
await agent.run()
```

**Поддерживаемые модели Ollama:**
| Модель | Возможности |
|--------|------------|
| **Qwen3-VL** | Лучшее качество, но тяжёлая [[41]] |
| **Qwen2.5-VL 7B** | Баланс качество/скорость [[1]] |
| **llava** | Базовый vision |
| **Llama 3.1 8B** | Текст без vision [[42]] |

**Установка:**
```bash
pip install browser-use
ollama pull qwen2.5vl:7b
```

> ⚠️ Важно: для полноценной работы с браузером нужна **vision-модель** (Qwen2.5-VL, Qwen3-VL). Текстовые модели (Llama) работают хуже [[41]].

### b) web-browser — плагин OpenCode (локальный Chromium)

**GitHub:** https://github.com/alexanderb1413/web-browser [[21]]

Это **плагин именно для OpenCode**, который даёт агенту встроенный браузер:

- Локальный Chromium-инстанс с **изолированным профилем**
- Скрипты на JS для навигации
- **Нет зависимости от Playwright** — использует Chromium напрямую [[21]]

**Установка:**
```bash
npm install -g @alexanderb1413/web-browser
# Добавить в конфиг OpenCode:
# "plugin": ["web-browser"]
```

**Использование в OpenCode:**
```
Агент получает инструменты:
- web-browser:navigate — открыть URL
- web-browser:screenshot — скриншот
- web-browser:click — кликнуть элемент
- web-browser:extract — извлечь текст/HTML
```

### c) Browser MCP / Browser MCP Local

**browser-use/browser-mcp** [[34]] и **MCP Servers Browser MCP Local** [[36]]:

- MCP-сервер, который подключается к **уже запущенному браузеру** (Chrome/Chromium)
- Не нужен отдельный Playwright/Puppeteer
- Совместим с OpenCode через MCP-конфиг

```json
// openCode.json
{
  "mcpServers": {
    "browser": {
      "command": "npx",
      "args": ["@browser-use/mcp-server"]
    }
  }
}
```

### d) Agent Browser (vercel-labs)

**GitHub:** https://github.com/vercel-labs/agent-browser [[40]]

CLI-инструмент **специально для агентов**:
- Команды: `navigate`, `click`, `type`, `screenshot`, `snapshot`
- Работает локально, без облака
- Легко интегрируется в OpenCode через shell-вызовы

```bash
agent-browser navigate "https://example.com"
agent-browser screenshot page.png
agent-browser extract --selector ".price"
```

## 📊 2. Парсинг данных и веб-поиск

### a) Ollama Web Search MCP

**GitHub:** https://github.com/nickscamara/ollama-web-search [[47]]

MCP-сервер, который даёт **локальный веб-поиск** моделям Ollama:

```json
// openCode.json
{
  "mcpServers": {
    "web-search": {
      "command": "npx",
      "args": ["ollama-web-search-mcp"]
    }
  }
}
```

- Поиск через DuckDuckGo / SearXNG (локально!)
- Извлечение контента страниц
- Работает **полностью локально**, без API-ключей

### b) local-search — плагин OpenCode

**GitHub:** https://github.com/jordanthe-creator/local-search [[49]]

Плагин для **поиска по локальным данным** (файлы, документы):

- Индексация локальных файлов
- Семантический поиск
- Интеграция с OpenCode «из коробки»

### c) Web Search MCP for OpenCode

**GitHub:** https://github.com/nickscamara/opencode-web-search [[50]]

Комбинирует:
- **Веб-поиск** (DuckDuckGo, SearXNG)
- **Извлечение контента** (readability, markdown-конвертация)
- **Парсинг страниц** (BeautifulSoup под капотом)

```json
{
  "mcpServers": {
    "web": {
      "command": "npx",
      "args": ["opencode-web-search-mcp"]
    }
  }
}
```

## 🐍 3. Python-агенты с Ollama

### a) Pydantic AI + Ollama

**Документация:** https://ai.pydantic.dev/models/ollama/ [[15]]

Это **фреймворк для создания агентов на Python** с нативной поддержкой Ollama:

```python
from pydantic_ai import Agent
from pydantic_ai.models.ollama import OllamaModel

model = OllamaModel('qwen2.5vl:7b', base_url='http://localhost:11434/v1')

agent = Agent(model, system_prompt='Ты агент для парсинга данных')
result = agent.run_sync('Спарси таблицу с сайта X и верни как JSON')
```

**Преимущества:**
- Строгая типизация через Pydantic
- Встроенная валидация результатов
- Поддержка tool calling
- Работает с локальным Ollama

### b) OpenManus — полноценный агент с browser-use

**GitHub:** https://github.com/mannaandpoem/OpenManus [[13]]

Это **полноценный автономный агент** на Python, который:
- Использует **browser-use** для браузера
- Поддерживает Ollama через конфигурацию
- Имеет планировщик, инструменты, память

```bash
# Конфигурация с Ollama:
# config.toml
[model]
provider = "ollama"
model_name = "qwen2.5vl:7b"
base_url = "http://localhost:11434/v1"
```

## 🔧 4. Микро-агент на Python (минимальный)

Если нужен **простой парсер** без тяжёлого фреймворка:

```python
# micro_agent.py
import ollama
import requests
from bs4 import BeautifulSoup

def parse_page(url: str, query: str) -> str:
    """Парсит страницу и отвечает на запрос."""
    resp = requests.get(url, timeout=10)
    soup = BeautifulSoup(resp.text, "html.parser")
    
    # Извлекаем текст
    text = soup.get_text(separator="\n", strip=True)[:5000]
    
    # Запрашиваем у локальной модели
    response = ollama.chat(
        model="qwen2.5:7b",  # или любая локальная модель
        messages=[{
            "role": "system",
            "content": "Ты парсер данных. Извлеки информацию из текста."
        }, {
            "role": "user",
            "content": f"Текст страницы:\n{text}\n\nЗапрос: {query}"
        }]
    )
    return response["message"]["content"]

# Использование
result = parse_page("https://example.com", "Какие цены указаны?")
print(result)
```

**Установка:**
```bash
pip install ollama requests beautifulsoup4
ollama pull qwen2.5:7b
```

## 🎯 Рекомендация для вашего стека

### Для браузера:
**browser-use** + Ollama Qwen2.5-VL — если нужен полноценный агент с vision.
**web-browser** плагин — если хотите браузер **внутри OpenCode** без внешнего Python.

### Для парсинга данных:
**Ollama Web Search MCP** — для поиска + извлечения.
**Микро-агент на Python** (ollama + requests + BS4) — для простых задач парсинга конкретных страниц.

### Для локальных данных:
**local-search** плагин — для поиска по файлам проекта.
**Pydantic AI** — если нужен структурированный агент с валидацией.

### Минимальный рабочий стек:
```bash
# 1. Браузер
pip install browser-use
ollama pull qwen2.5vl:7b

# 2. Парсинг
pip install requests beautifulsoup4

# 3. В OpenCode добавить MCP для веб-поиска
# openCode.json → mcpServers → web-search
```

Это даст вам **полностью локальный** агентный стек без облачных API.
