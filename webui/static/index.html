📄 Сводный файл

В поле «Пути» перечислите по одной строке директории и/или файлы. Директории собираются по типу проекта (авто / C# / Python / смешанные), отдельные файлы включаются как есть (кроме временных и > 100 КБ). «Собрать + отправить» — соберёт и отправит в ИИ; «Только собрать файл» — сохранит сводный файл.

📚 Промпты

Вкладка показывает все промпты из папки prompts/ (с наименованием, описанием и датой создания) и промпты из SQLite-базы. Нажмите на строку файла — содержимое откроется в текстовом поле. Кнопка «→ в сводный файл» вставит текущий промпт в окно «Локальный промпт».

💬 Вопрос — ответ (автоконвейер)

Общий промпт (можно не заполнять). Файл с вопросами — по одному на строку. Конвейер отправляет каждый вопрос в ИИ и записывает ответы в выходной файл.
