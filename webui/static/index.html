💬 Вопрос — ответ (автоконвейер)

Общий промпт (можно не заполнять — будет по умолчанию «ответь подробно в формате вопрос/ответ»). Файл с вопросами — по одному вопросу на строку. Конвейер отправляет каждый вопрос в ИИ, собирает историю и записывает ответы в выходной файл.

📄 Сводный файл

Собирает файлы проекта в один контекст. В начале — локальный промпт пользователя (вставьте в окно или выберите из базы), затем общее TDL-задание. «Собрать + отправить» — соберёт и отправит в ИИ; «Только собрать файл» — сохранит сводный файл без отправки.
