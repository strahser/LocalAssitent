Проанализируй код проекта LocalAssitent и дай рекомендации по улучшению.

## Описание проекта
LocalAssitent — это локальный AI-агент, который автоматизирует веб-интерфейс DeepSeek Chat через Selenium + Edge CDP. Проект работает на Windows и обеспечивает:
- Итеративную генерацию и выполнение Python-кода (code scenario)
- Пакетный Q&A (text scenario)
- Автоматическую аутентификацию
- Прикрепление файлов через input[type=file] и Ctrl+V
- Сведение документов для передачи внешнему ИИ (merge scenario)

## Задача
Проанализируй код и дай конкретные рекомендации по улучшению в формате:

### 1. Архитектура и структура
- Проблемы с текущей архитектурой
- Предложения по рефакторингу

### 2. Надежность и обработка ошибок
- Где не хватает обработки ошибок
- Как сделать код более устойчивым

### 3. Безопасность
- Какие проблемы безопасности есть
- Как их исправить

### 4. Производительность
- Где есть узкие места
- Как оптимизировать

### 5. Тестируемость
- Как лучше организовать тесты
- Какие тесты нужно добавить

### 6. Новые возможности
- Какие фичи стоит добавить
- Приоритет реализации

Для каждой рекомендации укажи:
- Конкретные файлы, которые нужно изменить
- Пример кода (если уместно)
- Приоритет (высокий/средний/низкий)

Ответ должен быть подробным, с примерами кода на Python.
